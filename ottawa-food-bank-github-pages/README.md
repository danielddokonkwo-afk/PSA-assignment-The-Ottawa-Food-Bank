# Ottawa Food Bank Resource Guide

This folder is ready for GitHub Pages. The website is in `index.html`.

## Publish it for free

1. Sign in to GitHub and create a **new public repository**. A simple name such as `ottawa-food-bank-guide` works.
2. Upload the contents of this folder to the repository. Make sure `index.html` is at the top level of the repository.
3. In the repository, open **Settings**, then **Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. GitHub will show the public website link after it publishes. It can take a few minutes.

For a simple personal web address, name the repository `<your-github-username>.github.io` instead. The site link will then be `https://<your-github-username>.github.io`.

## Notes

- The site is public once GitHub Pages is enabled.
- There is no form, login, or visitor data collection in this website.
- Update `index.html` whenever you want to change the wording or design.
